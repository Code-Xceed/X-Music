I am building a production-level Minecraft mod compatible with Fabric and Forge across versions 1.19 to 1.21.11 (including latest 26.x), also 1.16.5 and 1.8.9 forge. The mod is intended to function as a fully integrated in-game music and media system.

IMPORTANT ( I WOULD SUGGEST TO HANDLE LEGACY FORGE VERSIONS 1.8.9 AND 1.16.5 SEPARATELY, AS THEY HAVE DIFFERENT API STRUCTURES)

The system should support fetching and displaying complete music data (including user libraries, playlists, liked songs, and metadata) from Spotify and YouTube through proper and legal authentication mechanisms. It should also support local media playback (MP3/OGG files) and allow users to input YouTube links for video playback functionality similar to a standard video player, while respecting platform policies.

The mod should feature a modern, highly polished, production-quality user interface that blends seamlessly with Minecraft’s design language while maintaining a contemporary application feel. This includes a full music player interface, categorized navigation (Spotify, YouTube, Local), playlist management, and interactive controls.

Additionally, the system should include in-game HUD elements such as a mini-player, track info display, playback controls, and customizable overlays. The experience should feel smooth, optimized, and comparable to real-world music applications.

The entire system should be designed with scalability, modularity, and cross-version compatibility in mind. It should remain fully free to use, relying only on free tiers of APIs and services where applicable.

I will be providing a base/template mod setup to build upon.
